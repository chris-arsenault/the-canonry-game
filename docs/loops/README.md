# Active Gameplay Loops

This folder holds the current loop specifications that are actively being built into
the prototype simulation.

These are more concrete than [process design](../systems/process_design.md): they name
the loop anchor variables, the participating processes, and the balancing mechanisms
that keep the loop from becoming pure runaway growth or collapse.
